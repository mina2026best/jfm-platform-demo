## 摘要标准升级（2026-10-17 18:07，用户明确批评后举一反三）

**旧标准（已废弃）**：转述话题梗概 100-200 字——「该账号发布了 XX」式描述，无信息增量。

**新标准：观点蒸馏**（ai_summary 200-300 字，四段结构）：
1. **核心论点**——博主到底主张什么（一句话立场）
2. **关键细节/数据**——文案里的具体数字、学校名、时间节点、比喻（从 og:description 完整文案提取，不是从标题猜）
3. **对家长的实际含义**——这个观点若成立/不成立，家长该做什么、避免什么
4. **视角提醒**——博主的商业身份/数据口径/话术倾向，一句带过

**采集流程升级**：先直采视频页 og:description（douyin_meta_probe.py，无需登录，教育类视频简介即观点文案），再按四段结构蒸馏；只有 og:description 无实质文案时才降级为标题转述并标注「仅基于标题」。

**已实锤的工具**：douyin_meta_probe.py（8/8 成功率，含 /video/ /shipin/ 页面）。
