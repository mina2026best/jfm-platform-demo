03你需要亲手做的 5 步（全程唯一人工环节）

浏览器操作，约 3 分钟；无需绑卡、无需服务器

1

登录 EdgeOne Pages 控制台 需你本人

打开 pages.edgeone.ai → Sign Up / Log In → 用微信扫码或邮箱注册腾讯云账号（国内平台实名要求，只能由你本人完成）。建议直接用「GitHub 账号登录」，可省掉仓库授权一步。

2

新建项目并导入仓库

控制台首页选 Import Git Repository → 授权 GitHub → 选择 mina2026best/jfm-platform-demo（公开仓库，只读授权即可）。

3

构建设置（本站是纯静态单文件）

Framework Preset 选 None / 静态；Build Command 留空；Output Directory 填 ./（仓库根目录就是站点）。确认后点部署。

4

拿到国内可访问的正式地址

部署完成后获得 https://<你的项目名>.edgeone.app 形式的地址（前缀可在项目设置里改），自动 HTTPS，手机/电脑国内直连。

5

把后续更新交回给我（可选但推荐）

部署完成后告诉我一声即可——我会把新地址写进 README 并验证线上内容。若希望以后「我改完代码→自动更新线上」，可在控制台生成一个 API Token 发我（只授 Pages 权限），之后每次 git push 后我直接触发重新部署。

04上线后的日常更新流程

内容迭代不再需要重复部署动作

# 我在本机改 index.html → 本地 Playwright 回归验证通过后： git push origin main # 推送即触发 EdgeOne 自动重新部署（Git 集成模式） # 网络阻断时改走 GitHub Contents API 通道，效果相同

EdgeOne Pages 对接 GitHub 仓库后，main 分支的每次推送都会自动构建发布，无需人工干预——这与现有「git push 即上线」的迭代方式完全一致，网站更新节奏不变。

05备案问题，一次说清

使用 edgeone.app 免费二级域名：不需要任何备案。该域名由腾讯统一备案并持有，你只是在其下开子路径/子域。
将来要绑自有域名（如 jfm.example.cn）做国内加速时：才需要以你的名义做 ICP 备案（免费但需 1–2 周审核）。当前演示阶段用官方二级域名即可，备案这步暂时不存在。
