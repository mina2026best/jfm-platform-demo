01 · 升学日历

这个学期，别错过这些节点

16 个全年关键节点（覆盖幼升小 → 高考全学段），每条附「现在该做什么」行动清单与官方来源链接；节点每年微调，以官方发布为准。保存「孩子档案」后按学段自动过滤；支持提醒设置与行动清单打印。

2027-06幼升小

幼升小报名与材料准备

「三对口」材料清单、六年一户核查、长幼随学申请——以各区当年招生入学政策为准。

依据：各区教委当年招生入学政策
现在该做什么
✓ 备齐三对口材料（户口、房产、出生证明）
✓ 二孩家庭了解「长幼随学」申请通道
✓ 盯住网上报名窗口，错过要等统筹
2026-09小升初

转学与户籍材料核对

跨区转入家庭核对「三对口」材料与学位占用情况，错过转学的，正式版提供补救路径清单。

依据：渝教基函〔2025〕21号 及各区细则
现在该做什么
✓ 核对「三对口」材料：户口本、房产证、出生证明
✓ 查学位占用：问街道或原业主，比问中介靠谱
✓ 新房落户越早越好——部分区对落户年限有要求
2026-10初升高

指标到校资格摸底

市级重点高中招生计划的 70% 分配到辖区初中（渝教基函〔2025〕21号，已核验文号）；家长可核对学籍与连续就读要求。

来源：重庆市教委文件（已核验）
现在该做什么
✓ 确认孩子学籍连续（中途转学可能失去资格）
✓ 找班主任了解校内排位的参考口径
✓ 盯区教委当年细则：名额、条件每年微调
2027-04初升高

中考报名与联招志愿准备

2026 年联招学校约 113 所（第一批次市级重点约 94 所）；志愿填报窗口以次年 4 月政策公布为准。

来源：重庆日报 2026-04-22 政策口径
现在该做什么
✓ 盯 4 月政策发布：联招校名单、批次设置
✓ 提前拟志愿梯度：冲、稳、保各留 1–2 所
✓ 用平台「位次换算」估位置（正式版接入一分一段）
2027-06高考

高考特招线公布后行动清单

2026 年实际口径：特招线历史类 510 / 物理类 496；军检线（报考军校的体检参考）历史类男 517/女 631、物理类男 533/女 573。正式版自动替换当年口径。

来源：新华网重庆 2026-06-25（已核验）
现在该做什么
✓ 对照线差定位：过特招线多少分 → 位次区间
✓ 研究 3–5 个专业方向（兴趣 × 就业 × 分数匹配）
✓ 防志愿填报骗局：凡称「内部渠道/内部名额」的均按诈骗处理
2027-03幼升小

招生政策发布月：盯住区教委公告

每年 3–4 月各区教委发布义务教育招生入学工作通知（划片范围、材料清单、报名窗口）。这是全年最重要的「信息节点」——错过官方发布，只能靠二手信息。

官方入口：重庆市教委政策文件库 ↗
现在该做什么
✓ 收藏本区教委官网「招生入学」栏目
✓ 对照去年划片范围初判对口学校
✓ 有疑问直接打教委咨询电话（官方公布）
2027-06幼升小

网上信息采集与报名（义务教育入学「一件事」）

重庆义务教育入学已接入「渝快办」网上办理通道，幼升小信息采集集中在 6 月；材料线上核验，现场确认以各区安排为准。

官方入口：渝快办 · 重庆市政务服务网 ↗
现在该做什么
✓ 提前注册渝快办账号并实名认证
✓ 备齐户口/房产/出生证明扫描件
✓ 报名窗口开启当日提交，避开最后一天拥堵
2026-11小升初

期中考后定位：校内排位决定指标到校筹码

小升初已定，真正的变量是初中三年。期中考后关注孩子在年级的排位趋势——「指标到校」按校内排序分配，三年稳定在年级前列是最实在的筹码。

依据：市教委中考招生通知（指标到校 70% 口径）↗
现在该做什么
✓ 建立三年成绩曲线（别只看一次考试）
✓ 与班主任沟通年级排名口径
✓ 慎重对待转学：可能影响指标到校资格
2027-04小升初

初中招生政策发布与报名窗口

小升初与幼升小同窗口期（4 月政策、6 月报名）：民办超计划摇号、公办划片对口；「公民同招」下未摇中回公办统筹。

官方入口：市教委义务教育入学通知 ↗
现在该做什么
✓ 民办意向校查资质与往年摇号中签率
✓ 公办对口校实地走一遍通勤路线
✓ 摇号未中预案：确认统筹接收校情况
2026-12初升高

期末备考与体育项目冬训窗口

中考体育占分且过程性评价贯穿三年；冬季是耐力项目训练黄金期。期末成绩直接影响区统考排位与指标到校筹码。

官方入口：重庆市教育考试院 · 中考栏目 ↗
现在该做什么
✓ 体育弱项（长跑/跳绳）制定冬训计划
✓ 期末后对照区统考排位修正目标校
✓ 关注中考体育当年测试项目是否有调整
2027-06初升高

中考与出分：志愿窗口只有 3–5 天

中考 6 月中旬举行，出分后志愿填报窗口极短。冲稳保梯度要提前拟好——出分当天才知道线，没有时间从头研究。

官方入口：重庆市教育考试院 ↗（成绩查询与录取动态）
现在该做什么
✓ 出分前完成志愿草表（冲稳保各 1–2 所）
✓ 用「位次换算」工具交叉验证目标校
✓ 录取期间每天查考试院录取动态与征集志愿
2026-11高考

高考报名月（高三第一件事）

重庆高考报名通常在 11 月进行（应届生在学校统一办理）；随迁子女、社会考生需关注专项报名通道与材料。错过报名没有补报。

官方入口：重庆市教育考试院 · 高考栏目 ↗
现在该做什么
✓ 确认报名资格与所需证件（身份证有效期！）
✓ 艺体生同步确认统考报名
✓ 关注空军/民航招飞等专项报名时间
2027-01高考

期末统考（一模）：全市排位参考

高三上期末多区联考/全市统考，是一模定位的主要依据。用「线差 + 位次」双法对照目标院校近三年投档位次，校准志愿池。

站内工具：线差换算与位次查询（2025 官方一分一段）
现在该做什么
✓ 统考后用位次法对照目标校近三年投档位次
✓ 志愿池按「冲稳保」整理成表格
✓ 强基计划/综合评价关注高校报名窗口
2027-04高考

强基计划 / 综合评价 / 高校专项报名季

强基计划报名一般在 4 月（阳光高考平台统一入口），高校专项与综合评价窗口紧随其后；各校截止日不同，错过不补。

官方入口：阳光高考平台（浏览器打开）↗
现在该做什么
✓ 梳理孩子符合条件的专项类型
✓ 报名材料：成绩单/自荐信/获奖证明
✓ 逐校登记报名截止日（勿信最后一天）
2027-02高考

艺体统考成绩与校考季

艺术类统考成绩 1–2 月公布；校考院校在此期间组织专业考试。文化课不能停——综合分改革后文化课权重逐年上升。

官方入口：重庆市教育考试院 · 艺体统考通知 ↗
现在该做什么
✓ 统考成绩出来立即对照往年录取位次
✓ 校考行程提前规划（跨省考试留缓冲）
✓ 文化课复习计划不因校考中断
全年全阶段

资助申请窗口：别错过免学费与助学金

高中阶段城乡低保/特困学生免教科书等资助按学年申请（秋季学期集中受理）；中职免学费与国家助学金覆盖面更广。资助是申请制——不申请就没有。

官方入口：市教委高中免教科书通知 ↗
现在该做什么
✓ 开学两周内向学校提交资助申请
✓ 低保证/特困证等材料准备
✓ 中职家庭了解「中职国家助学金」覆盖范围
全年全阶段

转学窗口：学期初集中受理

义务教育阶段转学一般在学期初集中办理（政策依据：人籍一致与转学窗口管理）。注意：初中转学可能影响指标到校资格连续性——动迁家庭先算这笔账。

官方入口：市教委政策文件库（学籍管理类）↗
现在该做什么
✓ 先问转入校有无学位（官网公布咨询电话）
✓ 指标到校资格连续性先与区教委确认
✓ 材料备齐再跑流程，避免两头跑
