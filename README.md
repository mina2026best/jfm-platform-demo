> **🌐 线上访问**：https://mina2026best.github.io/jfm-platform-demo/

## 一、运行方式

- **最简单**：双击 `index.html`（Chrome/Edge/Safari 均可，无需服务器）
- **本地服务**（可选）：在本目录执行 `python3 -m http.server 8765`，访问 `http://localhost:8765/index.html`
- 移动端：手机浏览器打开同一文件，已做响应式适配（iOS/Android 均无横向溢出）

## 三、修改指南（改哪里）

所有内容都在 `index.html` 内：

- **学校数据**：搜 `SCHOOL_DB`（JS 对象；含简介/评价数组，新增学校会自动出现在档案库与对比下拉）
- **搜索索引**：搜 `SEARCH_DB`（新增模块时把条目加进去即可被全站搜索命中）
- **日历节点**：搜 `id="calendar"` 下的 `.cal` 卡片（含 `data-title` 提醒关键词）
- **政策条目与版本历史**：搜 `id="policy"` 下的 `.pol-item` 与 `details.vh`
- **行情表**：搜 `rent-table`
- **会员权益**：搜 `id="plans"`（价格在 `.price`；开通按钮绑 `openOrder(名称, 价格, 赠豆)`）
- **配色**：文件头 `:root` CSS 变量（--navy 主色 / --accent 强调色）
- **换算逻辑**：`var ZY`（特招线基准）与 `runZy()`；资金规划在 `fundCalc()`
- **本地存储键**：`jfm_alerts`（提醒）/`jfm_profile`（档案）/`jfm_cmp_fav`（对比收藏）

## 五、合规内置

不承诺升学结果 · 不做学科培训 · 不提供录取线与排名（对比器内说明）· 机构「资质审核 + 平台不背书」· 房源信息服务平台口径（不居间、不代收租金、费与成交脱钩）· 升学豆不可提现 · 会员协议勾选+退款规则明示+自动续费默认关闭 · 求真结论逐条带出处与核验日期 · 全国口径数据标注需本地校验 · 「清朗巴渝」红线已纳入审核词库（页脚声明）。

## 八、数据接入说明（v0.7 新）

**当前数据包**：`real-2026-09`（9/9 项已核验）。数据源注册表在 `index.html` 的 `DATA_SOURCES`（JS 对象），每项含 label/source/asOf/verified 四要素。接入新数据的步骤：

1. 在 `DATA_SOURCES` 追加或更新条目（来源四要素 + 核验状态）
2. 更新 `DATA_VERSION`（id/label/asOf）
3. 页面数字与 `dataBadge(key)` 徽标自动联动；「数据来源与核验」面板自动重渲染

**真实性验证记录（2026-09-17）**：志愿换算输出真实 2026 特招线（496/510，新华网重庆核验）+已核验徽标；资金规划输出 CIEFR 真实均值 15,828 元对照（30,000 元=190%）+报告名徽标；入学自查输出 70% 指标到校口径（渝教基函〔2025〕21号）+徽标；来源面板 9/9 全部「✓已核验」。排查记录：测试中发现 8765 端口被陈旧 http.server 占用导致回归误读旧页面，清除端口后 curl 预检+全量复测通过——这也验证了「验证环境要先核验」的纪律。
